# Instituto Vénus — website demo

Website demonstrativo responsivo para apresentar o Instituto Vénus, em Chimoio, e facilitar pedidos de informação.

## Ficheiros

- `index.html` — conteúdo e estrutura do site.
- `styles.css` — estilos, layout responsivo e versões para telemóvel.
- `script.js` — menu móvel, ano automático e comportamento demonstrativo do formulário.

## Ver o site

O projecto usa HTML, CSS e JavaScript simples. Não precisa de instalar dependências nem executar um processo de build.

## Publicar com GitHub Pages

1. Abra o repositório no GitHub.
2. Entre em **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Seleccione a branch principal (normalmente `main`) e a pasta `/ (root)).
5. Guarde e aguarde a publicação. O GitHub mostrará o endereço do site nessa página.

## Antes de publicar oficialmente

Este é um protótipo visual, não uma fonte oficial de informação institucional. Confirmar e actualizar:
- logótipo e identidade visual oficiais;
- contactos, telefone/WhatsApp, email e endereço exacto;
- lista oficial de cursos, nomes, requisitos, propinas e prazos;
- fotografias autorizadas do Instituto;
- formulário de contacto: actualmente é apenas demonstrativo e não envia dados.

Os cursos e áreas mencionados na página são referências iniciais fornecidas para a demonstração. Não foram adicionadas afirmações sobre acreditação, duração, resultados ou condições de admissão sem confirmação.

As fotografias de demonstração são servidas pelo Unsplash e precisam de ser substituídas por imagens autorizadas do Instituto, se necessário.
